# Свой сервер комнат для «Дурака»

Сервер только знакомит игроков друг с другом. Сами карты идут напрямую между телефонами, так что нагрузка у него крошечная.

## Запуск на компьютере

1. Установите Node.js 18 или новее (nodejs.org).
2. Запустите `start.bat` (Windows) или `./start.sh` (Mac, Linux). Первый запуск сам поставит зависимости.
3. Чтобы телефоны не из вашей сети тоже подключались, нужен бесплатный туннель Cloudflare: установите `cloudflared` (https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/). Скрипт запустит его сам и напишет адрес вида `https://что-то.trycloudflare.com`.
4. В приложении: Играть, Онлайн, «Сервер комнат», вставьте этот адрес. Ссылка-приглашение уже содержит адрес, друзьям вводить его не надо.

Адрес туннеля меняется при каждом запуске. Для постоянного адреса заведите именованный туннель Cloudflare со своим доменом и вставляйте его.

Только в домашней сети: адрес `http://IP-компьютера:9000` (без туннеля). Он работает в приложении для Android, но не на сайте по https.

Если поле «Сервер комнат» пустое, приложение использует общий сервер, как раньше.

Порт можно сменить переменной `PORT`.

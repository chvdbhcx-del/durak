# Дурак

Карточная игра «Дурак» с современным интерфейсом и продуманной тёмной темой. Работает в браузере, на Android и на iPhone из одной кодовой базы.

- Подкидной и переводной дурак
- От 1 до 5 соперников-ботов
- Колода на 24, 36 или 52 карты
- Тёмная и светлая темы, плавные анимации на каждом шаге, вибрация на телефоне
- Карты, иконка и оформление нарисованы с нуля

## Стек

React 18, TypeScript, Vite, Framer Motion. Правила игры лежат отдельно в `src/engine` и покрыты тестами. Нативные приложения собираются через Capacitor 8.

## Запуск

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты правил и ботов
npm run build    # сборка в dist/
```

## Телефоны

```bash
npm run build && npx cap sync
npx cap open android   # Android Studio
npx cap open ios       # Xcode (нужен Mac)
```

Каждый мерж в `main` выпускает [релиз](https://github.com/chvdbhcx-del/durak/releases/latest): APK для Android, архив с веб-частью и `update.json`. Установленное приложение раз в полчаса и при каждом открытии проверяет `update.json`, скачивает новую версию игры в фоне и предлагает перезапуститься. Если в релизе поменялась нативная часть (новые плагины Capacitor), приложение вместо этого предложит скачать новый APK.

APK подписывается ключом из секретов `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD` (алиас `durak`). Пока их нет, релиз подписывается тестовым ключом.

CI на каждом пулл-реквесте запускает тесты, собирает APK и проверяет сборку для iOS-симулятора. Чтобы поставить игру на настоящий iPhone, нужен Mac с Xcode и Apple ID, а для App Store ещё и аккаунт Apple Developer.

Веб-версия публикуется на GitHub Pages (ветка `gh-pages`) при каждом пуше в `main`: https://chvdbhcx-del.github.io/durak/. С телефона её можно добавить на домашний экран, и она будет работать как приложение, в том числе без интернета.

## Структура

```
src/engine/   правила, боты, тесты
src/ui/       интерфейс: стол, карты, настройки
android/ ios/ нативные проекты Capacitor
assets/       исходник иконки
```
